## 🤖 Personal agents

I am a personal agent maximalist. My agent, Alfred, runs on [Hermes Agent](https://github.com/NousResearch/hermes-agent), and these are the pieces I've built or open-sourced along the way.

- 🎙️ [hermes-talk](https://github.com/barronlroth/hermes-talk) — Realtime duplex voice for Hermes. Rides your ChatGPT or X Premium subscription, no API key needed. OpenAI, Grok, Gemini, from terminal, Discord, or the dashboard.
- 📻 [hermes-walkie-talkie](https://github.com/barronlroth/hermes-walkie-talkie) — Hermes plugin that lets one session message another existing session, waking it like a user turn.
- 🛠️ [Skills](https://github.com/barronlroth/Skills) — My agent skills plus a portable Skillfile that sets up any machine in one command.
- 🎧 [listen-later-podcast](https://github.com/barronlroth/listen-later-podcast) — Free podcast hosting on GitHub Pages, built so my agent can turn deep-dive research into episodes I listen to on my phone.
- 🦉 [alfred-hub](https://github.com/barronlroth/alfred-hub) — Public dashboards, guides, prototypes, and Alfred-flavoured experiments.
- 🧠 Contributing to [hermes-agent](https://github.com/barronlroth/hermes-agent), [OpenClaw](https://github.com/barronlroth/openclaw), [gbrain](https://github.com/barronlroth/gbrain), and [lossless-claw](https://github.com/barronlroth/lossless-claw) (lossless context management), the agent harnesses, memory, and context layers Alfred runs on.
